# Summary
This is a priority queue application for students and professors to queue their questions and topics for office hours. It will have two parts: student and professor. Student part will have a simple input for their question and it will output a number in the queue based on relevance/importance of their question. Professor part will have different features including view of the queue, changing the queue.

# Textstack
- Front end - React
- Back end - Flask
- Database - SQL Light
